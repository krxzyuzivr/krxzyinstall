# Trademarks and official builds

The **krxzyinstall** name, icon, and official signing certificate identify the
project maintained by krxzyuzivr.

Only APKs signed with this certificate are official krxzyinstall builds:

```
Certificate SHA-256:
d3c9d7b5f7012a996d450f6066e3053d8a7f950b10bf71803a76921041ed0ae4
```

Forks are welcome under the GPLv3, but a modified build must not be presented
as an official krxzyinstall release or use the official certificate. If the
certificate does not match, the build came from someone else.

This is a trademark and project-identity policy. It does not reduce the rights
granted by the GNU GPL v3.0 for the source code.
