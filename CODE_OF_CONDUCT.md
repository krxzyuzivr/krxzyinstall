# Code of conduct

## The short version

Be respectful, stay on topic, and assume good faith. This is a hobby project
for helping people install their own games on a headset.

## Please do

- Be clear and patient, especially with people who are new to sideloading.
- Keep bug reports focused on reproducible behavior.
- Credit other people's work when you build on it.
- Respect the project's licenses, credits, and trademark policy.

## Please do not

- Harass, insult, threaten, or discriminate against anyone.
- Post pirated games, paid APKs, OBBs you do not have the right to share, or
  links to them.
- Post someone else's personal information, account tokens, or private logs.
- Spam, repeatedly bump issues, or open drive-by pull requests that ignore
  the contributing guide.
- Present modified builds as official krxzyinstall releases.

## Enforcement

Maintainers may edit, lock, or remove issues, comments, and pull requests that
break these rules, and may block accounts that repeatedly do so. If you need to
raise a conduct concern privately, contact the maintainer through their GitHub
profile: <https://github.com/krxzyuzivr>.

This code of conduct applies in the repository, issue tracker, pull requests,
and other project spaces.
